Fly Safe 0.10.1

macOS Apple Silicon
1. Open Fly-Safe-0.10.1-arm64.dmg.
2. Drag Fly Safe to Applications.
3. Launch Fly Safe normally. The public release must be Developer ID signed and notarized.

Windows x64
1. Copy Fly-Safe-Setup-0.10.1-x64.exe to the PC completely.
2. Verify the Fly Safe Authenticode signature, then run the installer.
3. If NSIS reports an integrity error, delete the damaged copy and download the
   same public installer again. There is no portable public fallback.

Updating preserves the local license, EVE SSO, settings, contacts and caches.
Release scripts fail closed when signing, notarization, entitlement or HTTPS update
configuration is missing. Never distribute an ad-hoc or unsigned package.
