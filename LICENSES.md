# Закрытый доступ и выдача лицензий

Приложение принимает два Ed25519-формата: legacy `EVEI1` для ручной поддержки и короткий online entitlement `EVEI2`, привязанный к персонажу, подписке и устройству. Ограниченный EVE SSO доступен до лицензии; разведка и остальные IPC открываются только после действующего entitlement. Приватный ключ не входит в исходники, DMG или Windows EXE.

Основной production-поток реализован в `server/`: invoice → входящий ISK в wallet journal cashier-персонажа → credit/subscription → `EVEI2`. Ручные `EVEI1` ниже оставлены как аварийный канал.

## Где хранится центр лицензий

На Mac владельца по умолчанию:

```text
~/Library/Application Support/EVE Local Intel License Authority/
```

- `ed25519-private.pem` — секрет выдачи лицензий. Права `0600`.
- `ed25519-public.pem` — публичный ключ для проверки.
- `issued/` — выданные файлы `.license` и метаданные.

Сделайте отдельную резервную копию `ed25519-private.pem`. Не отправляйте этот файл клиентам и не кладите его в проект. Потеря ключа лишит вас возможности выпускать совместимые лицензии; утечка позволит выпускать поддельные.

## Выдать ключ

1. Клиент запускает программу на Windows или macOS и присылает показанный `Код устройства`.
2. Выпустите лицензию на нужный срок:

```bash
npm run license:issue -- \
  --device-code ELI-XXXX-XXXX-XXXX-XXXX-XXXX \
  --customer "Имя клиента" \
  --days 365
```

Бессрочный ключ:

```bash
npm run license:issue -- \
  --device-code ELI-XXXX-XXXX-XXXX-XXXX-XXXX \
  --customer "Имя клиента" \
  --lifetime
```

Команда печатает путь к созданному `.license`, но не выводит сам ключ в терминал. Передайте клиенту содержимое только этого файла. Файл `.json` рядом — ваши метаданные.

Ключ всегда платформенно независим по формату, но привязан к одному коду устройства. Поэтому лицензия текущего Mac не активирует Windows-компьютер: для Windows нужно один раз выпустить отдельный ключ по коду, показанному в Windows-приложении.

Проверить выданную лицензию:

```bash
npm run license:inspect -- --file "/полный/путь/к/ключу.license"
```

## Владелец программы

Для текущего Mac владельца уже выпущена бессрочная лицензия:

```text
~/Library/Application Support/EVE Local Intel License Authority/issued/OWNER-SERGEY-2026.license
```

Откройте этот файл обычным текстовым редактором и вставьте его содержимое в окно активации версии 0.6.0.

## Ограничения офлайн-защиты

- Ключ нельзя перенести на другой компьютер: код устройства не совпадёт.
- Поддельный или изменённый ключ не пройдёт Ed25519-проверку.
- Без лицензии main-процесс разрешает только EVE SSO, subscription/invoice и безопасные shutdown-команды; ESI-функции, zKillboard, буфер и локальные базы остаются закрыты.
- `EVEI2` дополнительно сверяется с ID вошедшего персонажа. Передача токена другому персонажу или устройству не открывает программу.
- Офлайн-лицензия не умеет мгновенно отзывать уже выданный ключ и контролировать число одновременных запусков.
- Production-сборки требуют Authenticode либо Developer ID + notarization и получают обновления только через подписанный release-контур. Клиентская проверка всё равно не заменяет короткий серверный entitlement.
